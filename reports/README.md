# 评审与复盘归档

本目录存放文档站的历次评审报告，**不属于站点构建产物**，不会被 Docusaurus 打包。

从根目录迁入，目的是让项目根保持「可执行工程」的样子：一眼能看出哪些是要跑的东西、哪些是读过就算的产物。

## 目录约定

| 位置 | 内容 |
|------|------|
| `reports/*.md` | 文档质量 / 架构 / 对标类评审报告，按时间顺序编号阅读即可 |
| `reports/pdf-export/` | 与文档站无关的一次性 PDF 导出脚本（reportlab 输出到桌面绝对路径），保留仅为可追溯，日常不运行 |
